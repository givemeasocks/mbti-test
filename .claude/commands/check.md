이 저장소의 모든 `.html` 파일을 대상으로 아래 3가지 항목을 점검하라. 이 프로젝트는 서버/API 없이 정적 파일로만 구성되므로, 정적 분석과 (가능하다면) 브라우저 확인을 함께 사용한다.

## 점검 항목

1. **제목(title)**
   - 각 HTML 파일에 `<title>` 태그가 존재하는지 확인한다.
   - 비어 있거나("<title></title>"), 기본값("Document" 등 플레이스홀더)이면 수정필요로 표시한다.

2. **깨진 링크**
   - 각 파일의 `href`, `src` 속성을 모두 추출한다.
   - 내부 상대 경로(로컬 파일 링크)는 실제로 해당 파일이 존재하는지 확인한다.
   - 외부(`http://`, `https://`) 링크는 형식만 확인하고, 필요시 접속 가능 여부는 별도로 언급한다(자동 요청은 과도하게 하지 않는다).
   - `#`로 시작하는 앵커 링크는 같은 파일 내 해당 `id`가 존재하는지 확인한다.

3. **콘솔 에러**
   - Chrome 브라우저 자동화 도구(claude-in-chrome)를 사용할 수 있으면, 각 HTML 파일을 로컬에서 열어 콘솔 에러/경고를 확인한다.
   - 브라우저 도구를 사용할 수 없는 환경이면, 정적 분석으로 대체한다: `<script>` 태그가 참조하는 JS 파일이 실제로 존재하는지, 문법 오류가 뚜렷한지 등을 확인하고 "브라우저 미확인" 임을 결과에 명시한다.

## 절차

1. `Glob`으로 저장소 내 모든 `*.html` 파일 목록을 수집한다.
2. 각 파일을 읽고 위 3개 항목을 순서대로 점검한다.
3. 발견된 문제는 구체적으로 기록한다 (예: "3번째 줄 href=\"about.html\" → 파일 없음").

## 보고 형식

점검이 끝나면 아래와 같은 마크다운 표로 결과를 정리해서 보고한다. 표는 파일별로 한 행씩 구성한다.

| 파일 | 제목 | 깨진 링크 | 콘솔 에러 | 종합 |
|---|---|---|---|---|
| index.html | 통과 | 통과 | 통과 | ✅ 통과 |
| about.html | 수정필요 (제목 비어있음) | 수정필요 (href="team.html" 파일 없음) | 미확인 | ⚠️ 수정필요 |

표 아래에 "수정필요" 항목이 있는 파일에 대해서는 구체적인 수정 제안을 짧게 덧붙인다. 문제가 없으면 바로 수정하지 말고 먼저 보고만 한다.
